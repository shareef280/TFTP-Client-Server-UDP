# TFTP Client and Server Using UDP Socket Programming

## 📌 Project Overview

The **Trivial File Transfer Protocol (TFTP)** is a simple file transfer protocol that enables communication between a client and a server over a network.

This project explores TFTP-based file transfer using **C programming and UDP socket programming** in a Linux environment. It focuses on client-server communication, request and response handling, file operations, and different file transfer modes.

The client implementation supports file upload and download operations and provides an opportunity to understand how application-layer protocols work over UDP.

## 🎯 Project Objectives

* Understand UDP socket programming in C.
* Implement client-server communication for file transfer.
* Perform file upload and download operations.
* Understand TFTP request, data, and acknowledgement packets.
* Explore Normal, Octet, and Netascii transfer modes.
* Gain practical experience with Linux networking APIs and file handling.

## ✨ Key Features

* **UDP Communication:** Uses UDP sockets for network communication.
* **File Download (GET):** Requests a file from a compatible TFTP server.
* **File Upload (PUT):** Sends a file to a compatible TFTP server.
* **Multiple Transfer Modes:** Includes Normal, Octet, and Netascii modes.
* **Packet Handling:** Works with transfer requests, data packets, and acknowledgements.
* **File Operations:** Uses file handling and Linux system calls to read and write file data.
* **Client-Server Architecture:** Demonstrates communication between a client and a server over a network.

## 🌐 How UDP Communication Works

UDP is a connectionless transport-layer protocol. Unlike TCP, it does not establish a connection before sending data.

In a typical TFTP exchange:

1. The client sends a transfer request to the server.
2. The server responds with data or an acknowledgement, depending on the operation.
3. The client and server exchange data and acknowledgements.
4. The transfer continues until the final data block is received or sent.

TFTP implementations must handle packet sequencing, timeouts, retransmissions, and transfer errors appropriately.
